# ГеоСлед

«ГеоСлед» — браузерная игра-тренажёр по странам и столицам. Игрок выбирает регион мира, получает название страны, отмечает её на карте и вводит столицу. Одна партия состоит из 10 раундов; за карту и столицу начисляются отдельные баллы.

Проект полностью статический: ему не нужны серверная часть, база данных, ключи API, npm-зависимости или этап сборки. Карта, данные и шрифты включены в репозиторий, поэтому сайт подходит для бесплатной публикации через GitHub Pages.

## Возможности

- регионы: весь мир, Европа, Азия, Африка, Северная Америка, Южная Америка и Океания;
- интерактивная карта без подписей и отдельный список стран для управления с клавиатуры;
- проверка карты и столицы, подсказка после ошибки и итоговая статистика;
- сохранение текущей партии и лучшей серии в `localStorage` браузера;
- адаптивная вёрстка для компьютеров и мобильных устройств;
- кнопка «Подарок»: шестисекундный ролик со звуком поверх игры, с удалением зелёного фона;
- интерфейс и названия стран на русском языке.

## Локальный запуск

Открывать `index.html` двойным щелчком не следует: браузеры обычно блокируют загрузку JSON-файлов через протокол `file://`. Запустите простой локальный HTTP-сервер из корня проекта.

### Вариант с Python

```powershell
python -m http.server 4173
```

Затем откройте [http://localhost:4173](http://localhost:4173).

Если команда `python` в Windows не найдена, попробуйте:

```powershell
py -m http.server 4173
```

Для остановки сервера нажмите `Ctrl+C` в терминале.

## Публикация на GitHub Pages

GitHub Pages бесплатно размещает статические сайты из публичных репозиториев.

1. Войдите в GitHub и создайте новый **public**-репозиторий, например `geosled`.
2. Загрузите **содержимое этой папки** в корень репозитория. Файл `index.html` должен находиться в корне, а не внутри дополнительной папки `geosled`.
3. Откройте страницу репозитория и перейдите в **Settings → Pages**.
4. В разделе **Build and deployment** выберите:
   - **Source:** `Deploy from a branch`;
   - **Branch:** `main`;
   - **Folder:** `/(root)`.
5. Нажмите **Save**. Первая публикация обычно занимает несколько минут; состояние развёртывания видно на вкладке **Actions**.
6. После публикации сайт будет доступен по адресу:

   ```text
   https://<имя-пользователя>.github.io/<имя-репозитория>/
   ```

Все пути в проекте относительные, поэтому дополнительная настройка для адреса с именем репозитория не требуется. Файл `.nojekyll` отключает обработку Jekyll и позволяет GitHub Pages отдавать структуру проекта без преобразований.

### Обновление опубликованного сайта

Измените файлы в ветке `main` и отправьте новый коммит. GitHub Pages автоматически запустит повторную публикацию. Если браузер показывает старую версию, дождитесь завершения workflow на вкладке **Actions** и обновите страницу с очисткой кеша.

## Данные и приватность

Сайт не отправляет ответы на сервер. Игровой прогресс хранится только в `localStorage` текущего браузера. Для сброса прогресса можно удалить данные сайта в настройках браузера.

Список стран и столиц сформирован из `world-countries` и меток Wikidata; границы взяты из `world-atlas`, основанного на данных Natural Earth. Подробная атрибуция и условия использования приведены в [THIRD_PARTY_NOTICES.md](./THIRD_PARTY_NOTICES.md).
